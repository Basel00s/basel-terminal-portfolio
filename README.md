# Basel Terminal Portfolio

A terminal-inspired personal portfolio built with Next.js App Router, JavaScript, React, and CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customize

- `components/TerminalPortfolio.jsx`: edit the introduction, commands, projects, skills, and GitHub links.
- `app/globals.css`: change colors, typography, spacing, and responsive styles.
- `app/layout.js`: edit the page title and description.

## Terminal commands

`help`, `about`, `projects`, `skills`, `stack`, `contact`, `clear`

Project links and contact details are starter content. Replace them with your real links before publishing.
